# Logos

Drop logo files here, named by the slug below, as `.svg`, `.png` or `.webp`
(square works best, about 128×128 px). Example: `sbi.png`, `star-health.svg`.

They are bundled with the app, so they work offline and no outside site learns
which banks or services you use. The app matches an item to a logo by its Bank,
Insurer, Issuer, Lender, Provider, Brand or Organisation field, or by its name
(for subscriptions). Items without a logo show their category icon.

To add a name that isn't listed, add a line to `src/lib/logos.ts`.
